Data Analytics Internship – Task 10 (Simple KPI Tracking Sheet)

This repository contains my submission for Task 10 of the Data Analytics Internship.

Dataset - Sample Superstore Dataset

Objective - The objective was to build a simple KPI summary that automatically calculates important business metrics from raw order data.

Tools Used
1. Google Sheets
2. Sample Superstore Dataset
3. GitHub

KPI Tracking Performed
1. Calculated Total Sales
2. Calculated Total Units Sold
3. Calculated Average Order Value
4. Identified the Top Sub-Category based on total sales
5. Used formulas that automatically update when new rows are added to the raw data

Key Findings
1. The KPI sheet provides a quick summary of overall sales performance
2. Total Sales and Total Units Sold show the overall sales activity
3. Average Order Value shows the average sales value per transaction
4. The Top Sub-Category identifies the sub-category with the highest total sales

Files
1. Task 10.xlsx - KPI tracking workbook containing the raw data and KPI summary
2. README.md - Summary of the KPI tracking project

Conclusion - The Sample Superstore dataset was used to create a simple KPI tracking sheet in Google Sheets. The sheet automatically calculates key business KPIs and can update when new order data is added.
